# Design Brief — hanpeng 个人网站 V2

**Companion docs:** `PRD.md`、`TECHNICAL_SPEC.md`
**Last updated:** 2026-10-02

---

## 1. 一句话主题

hanpeng 是一个**独立构建产品、研究 AI、自己搭基础设施**的工程师。网站应该让人感到：克制、精确、有真实作品——像一个正在运转的工作台，而不是一份海报。

## 2. 设计语言

三种气质的混合，但形成自己的语言：**Editorial × Engineering × AI**。

- **Apple** —— 留白、排版节奏、少即是多
- **Stripe** —— 信息结构、产品感、内容层级清晰
- **Vercel** —— 工程师气质、等宽字点缀、暗色工程感

## 3. 设计论点

网站的行为应该像它的主人：**持续构建、可观测、不喧哗**。状态徽章（呼吸的绿点）、等宽字的编号与状态（BUILDING / EXPLORING / RUNNING）、终端式光标——这些是"工程感"的来源，而不是装饰。

## 4. 视觉规则

- **色彩**：深浅双主题；绿色（--pass）表示"活着/在线/通过"，蓝色（--brand）为品牌主色。不引入新色相。
- **字体**：Space Grotesk / Instrument Serif 做展示层，Inter 做正文，JetBrains Mono 做编号、状态与标签；中文回退 PingFang SC / 微软雅黑。
- **布局**：单列内容流，区块之间用「标题 + 细线」分隔；卡片只在需要聚合信息时出现。
- **动效**：只保留有含义的——呼吸状态点、展开折叠、主题圆形揭示；`prefers-reduced-motion` 下全部静止。

## 5. 克制清单（不做的事）

❌ 粒子背景 / 3D / 鼠标跟随光效
❌ 技术 logo 铺满页面
❌ 大型 GitHub contribution graph
❌ 过度玻璃拟态
❌ 首页塞超过 3 个项目

> 页面最大的优势是**克制**。升级永远是增加内容深度，而不是视觉噪音。

## 6. 各区块视觉要点

| 区块 | 要点 |
|---|---|
| Hero | 大号姓名 + 光标闪烁；等宽字双行定位（中文职称 + Independent Developer · AI Builder）；照片保留 bracket / 城市 / 在线状态三件套 |
| What I Build | 三张编号卡（01/02/03），大写等宽标题 + 一句 headline + 一段说明 |
| Projects | 族记为主角卡；展开面板承载「架构亮点」；卡片悬停/点击展开逻辑保持 |
| AI Lab | 2×2 实验卡，等宽标题 + 标签行，像实验记录而非广告 |
| Philosophy | 纯文字两列，编号 + 英文信念 + 中文注解——留白即设计 |
| Now | 状态点 + 等宽状态词 + 行式列表；右上角「更新于 YYYY-MM」 |
| 技术栈 | 分组标签 + 实战注脚；整节视觉权重低于项目 |
| Contact | 双问句 + 双 CTA；AI 分身提示语只在机器人启用时出现 |
